# Security policy

This is wallet software; take any suspected vulnerability seriously and
report it privately.

Email **drey@squirrelsystems.net**. Do not open a public issue for a
vulnerability.
Include what you found, how to reproduce it, and what an attacker could do
with it. You should hear back within a few days.

In scope: the code in this repository and the published recovery-tool
artifacts whose digests are recorded in `recovery/RELEASES.md`.

Please don't test against wallets or infrastructure you don't own.
