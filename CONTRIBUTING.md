# Contributing

This repository is the public release mirror of a private working repository.
History here is one squashed commit per release; development happens
privately and each release is pushed as a snapshot.

Bug reports and feature requests are welcome as issues. For anything
security-sensitive, use the process in `SECURITY.md` instead of a public
issue.

**Pull requests are not accepted yet.** The code is AGPL-3.0-only, and before
merging outside work we need a contributor license agreement in place that
preserves our ability to relicense original code. Until then, PRs will be
closed — with thanks, and with the issue kept open so the underlying problem
isn't lost.
